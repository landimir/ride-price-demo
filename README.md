# Ride Price — Training Demo (static hosting)

Public static hosting of the Ride Price **demo/training tool**: the dealer
desking portal and the sales training hub.

- **Everything here is fictional.** All personas, phone numbers, addresses and
  documents are training fixtures; sample SSNs are always `000-00-0000`.
- The license "scanner" recognizes only the five printable training props —
  there is no code path that reads a real ID.
- No backend, no accounts, no data collection. Each browser keeps its own demo
  state locally and can reset it at any time.

This repo is generated from the private source repository; edits belong there.
